Saving Progress

Browsers have a place to save small bits of text for a website, called localStorage. Anything saved there is still there after the page is closed, so it's good for high scores, unlocked levels, and settings.

Press space to start, then press it as many times as you can in five seconds. Your best score is saved, so it's still there if you refresh the page.

How it Works

localStorage.setItem(name, value) saves a value under a name, and localStorage.getItem(name) gets it back. If nothing has been saved yet, getItem() gives back null, so ?? 0 starts the best score at 0.

Everything is saved as text, so Number() turns the best score back into a number when it's loaded.

Saving More Than One Thing

To save a lot of things at once, put them in an object, and turn it into text with JSON.stringify(). JSON.parse() turns it back:

const saveName = "my-game-save";

// Load the save, or start fresh if there isn't one yet
let save = JSON.parse(localStorage.getItem(saveName)) ?? {level: 1, coins: 0, music: true};

function saveGame() {
    localStorage.setItem(saveName, JSON.stringify(save));
}

// Later, like when a level is beaten:
save.level++;
saveGame();

To erase the save, like for a "New Game" button, use localStorage.removeItem(saveName).

Things to Know

  • Give your save a name only your game uses. Every page on the same website shares one localStorage. On GitHub Pages, that's every project on your account, so a name like "score" could clash with another game. A name like "my-game-best" won't.
  • Saves stay on one browser. They don't move to other computers, and private windows forget them when they're closed.
  • Players can change them. Anyone can edit localStorage from the browser's developer tools, so don't trust it for anything that matters, like an online leaderboard.
