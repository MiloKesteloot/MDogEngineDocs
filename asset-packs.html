Asset Packs

Art to use in your games. Everything here is already built into the Playground and the demos, so the code works there as is. For your own project, download the files and put them in your assets folder, keeping the same folders (see Where Do My Files Go?).

Each one comes with code to use it. Copy it, then change x and y to where it should be drawn.

Warrior

A warrior with a sword, with 22 animations for running, jumping, attacking, and more. The art is by Clembod, from the Warrior Free Animation Set on itch.io.

Click an animation to see the code for it. Animations that play once, like Attack and Death, are shown on repeat here so they're easy to see. In a game, use getRawFrame() to tell when they're done (see Animation Methods).

Lining Her Up

  • Her feet are always at y 42 in the picture, so draw her at feetY - 42 to stand her on the ground.
  • She's about 18 pixels wide, starting about 18 pixels in from the left of each frame. A hitbox like new MDog.Basics.SquareKickbox(position, 0, 0, 14, 30), with the picture drawn 19 pixels to the left of it, fits her well (the Tutorial does this).
  • Some animations are 69 pixels wide instead of 64 (Crouch, Dash, Dash Attack, Slide, Wall Slide, Edge Grab, Edge Idle, and Ladder Grab). The extra space is on the right, so she lines up with the others as is. When she's flipped with flipX, draw those 5 pixels further left.
  • Some animations come in two versions, with and without dust or effects, so the effects can be left off or made with particles instead.

Tiles

Four 16 by 16 tiles in one row, for tilemaps: grass is 0, dirt is 1, stone is 2, and water is 3. The Levels From a File guide uses them.

Fonts

The two pixel fonts textImage() can draw with. They have letters, numbers, and !~-.,?[]/:*'"<>_. Any other character is left as a space.
