Timers and Cooldowns

Lots of things in games happen after a while: an enemy that spawns every few seconds, a power-up that runs out, or a gun that can only shoot so fast. In MDog Engine, the simplest way to time things is to count ticks. The active function runs 160 times per second, so 160 ticks is one second.

Hold space to shoot. The cannon can only shoot once every quarter of a second, and the light in the corner blinks once a second.

Cooldowns

A cooldown is a number of ticks to wait. When the cannon shoots, cooldown is set to 40, and it goes down by one every tick. The cannon can only shoot again once it's back to 0.

Every So Often

ticks goes up by one every tick. ticks % 160 counts from 0 to 159 over and over, so something can happen once a second:

if (ticks % 160 === 0) {
    spawnEnemy();
}

The blinking light uses the same trick. ticks % 160 < 80 is true for the first half of every second.

Waiting, Then Doing Something

To wait before something happens, count down to it, like a power-up that lasts five seconds:

let powerUpTicks = 0;

function collectPowerUp() {
    powerUpTicks = 5 * 160; // Five seconds
}

function main() {
    if (powerUpTicks > 0) {
        powerUpTicks--;
        if (powerUpTicks === 0) {
            // The power-up just ran out
        }
    }
}

Why Not setTimeout()?

JavaScript's setTimeout() waits a number of milliseconds, but it doesn't know about the game. It keeps counting while the game is paused, and when the browser tab is hidden. Counting ticks keeps timers in step with everything else in the game.
