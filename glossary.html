Glossary

What the words in these docs mean. Around the docs, the first time one of these words shows up on a page, it's underlined with dots. Hold the mouse over it to see what it means, or click it to come here.

Active Function

The function MDog Engine runs every tick, set with MDog.setActiveFunction(). Changing it is how a game switches screens, like from a title screen to the game.

Animation

Pictures shown one after another, made with MultipleFileAnimation (one file per frame) or SpriteSheetAnimation (every frame in one file), and drawn with MDog.Draw.animation(). Each time it's drawn, it moves forward by one tick.

Art Pixel

One pixel of the game's own small screen. The screen is 512 by 384 art pixels unless it's changed with setScreenSize(), and each art pixel is drawn as a square of real pixels, so the game is scaled up without getting blurry. Every position in a game is in art pixels.

Assets Folder

The folder named assets next to a game's index.html, where its images, fonts, and other files go. MDog Engine adds assets/ to the start of every file name, so "player.png" means assets/player.png.

Camera

In the ThreeDee Module, where a 3D scene is seen from. In 2D games, a "camera" that follows the player is made by shifting everything with translate() (see A Camera That Follows the Player).

Clicked

True for only the one tick a key or mouse button is first pressed, from isClicked() or getClick(). Good for things that should happen once per press, like jumping.

Down

True for every tick a key or mouse button is held, from isDown() or getDown(). Good for things that keep happening while it's held, like walking.

Frame

One picture of an animation. Animations count frames from 0 in code, but the files of a MultipleFileAnimation are numbered from 1.

Hex Code

How colors are written, like "#ff8800": a #, then two digits each for red, green, and blue, from 00 (none) to ff (all). Two more digits at the end, like "#00000099", make it see-through.

Hitbox

An invisible shape used to check if things touch, usually simpler than what's drawn. In MDog Engine, hitboxes are kickboxes.

Interactable

Something from the UI Module that's drawn on the screen and can tell where the mouse is, like a tilemap or a grid. Drawn with MDog.Draw.interactable(), or in a Page.

Kickbox

MDog Engine's name for a hitbox. A SquareKickbox is a rectangle attached to a position Vector, so it moves along with whatever it belongs to.

Layer

One of the game's canvases. Layers are numbered, and higher ones are drawn on top of lower ones, so a background can be on layer 0 and the player on layer 1. Drawing methods take a layer setting.

Module

One part of MDog Engine, like MDog.Draw or MDog.Input. Each has its own page under Engine in the sidebar.

Particle System

A group of particles that are moved and drawn together. Particles are small things that fly around for a while and then disappear, like sparks and dust (see the FX Module).

Pixel Font

A font made of pixel art, drawn with textImage(). MDog Engine comes with two: marsfont.png and determinationfont.png (see Asset Packs).

Settings

The last thing many methods take: an object of extra options, like {flipX: true, scale: 2}. Every setting has a default, so only the ones that matter need to be written.

Sprite Sheet

One image with every frame of an animation side by side, from left to right. Made into an animation with SpriteSheetAnimation.

Tick

One run of the active function. MDog Engine runs 160 ticks per second on every computer, so moving something 1 art pixel per tick always moves it 160 art pixels per second. Timers in games are usually counted in ticks (see Timers and Cooldowns).

Tilemap

A grid of small square pictures called tiles, all from one sprite sheet, written as rows of tile numbers. Made with TilemapInteractable, often from a .csv file (see Levels From a File).

Vector

A point or direction with an x and a y (or an x, y, and z for a Vector3), from the Math Module. Used for positions, speeds, and directions.
