Levels From a File

Typing a level into your code works for a small one, but a level in its own file is easier to change. A .csv file is plain text, with a number for each tile, commas between them, and one row per line. Spreadsheet programs and level editors like Tiled can save them.

This is assets/levels/level1.csv. -1 is an empty tile, and the other numbers are tiles from tiles.png: 0 is grass, 1 is dirt, 2 is stone, and 3 is water.

The game loads the file with the Asset Manager, waits for it, then turns it into a TilemapInteractable from the UI Module. Move the mouse over the level to see the tile numbers.

How it Works

loadFile() starts loading the file in the background, and saves it under the name "level1". Until doneLoading() is true, the game only shows "Loading...".

On the first tick the file is ready, get("level1") gives back the file's text, which is exactly what TilemapInteractable takes. The tiles are 16 pixels, and tiles.png is 4 tiles wide.

Solid Tiles

To have the player stand on the level, check the tile at a position. screenToTile() turns a position into a tile position, and get() gives back the tile number there:

// Grass, dirt, and stone are solid. Water and empty tiles aren't.
function isSolid(x, y) {
    const tile = level.screenToTile(x, y);
    const number = level.get(tile.x, tile.y);
    return number === 0 || number === 1 || number === 2;
}

// Is there ground just under the player's feet?
const onGround = isSolid(player.x, player.y + 16) || isSolid(player.x + 15, player.y + 16);

More Levels

Load every level at the start, each with its own name, and switch between them by making a new tilemap:

MDog.AssetManager.loadFile("levels/level1.csv", "level1");
MDog.AssetManager.loadFile("levels/level2.csv", "level2");

function startLevel(number) {
    level = new MDog.UI.TilemapInteractable(0, 0, MDog.AssetManager.get("level" + number), 16, "tiles.png", 4);
}
