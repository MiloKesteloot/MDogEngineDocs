Getting Started

This page walks through making a small game where you move a square around with the arrow keys. You don't need to download MDog Engine, since your game imports it from the web.

1. Make the Project

Make a new folder for your game, with these files in it:

my-game/
    index.html
    game.js
    assets/

The assets folder is where your images and other files go. Whenever MDog Engine asks for a file name, it looks inside this folder.

2. Make the Web Page

Put this in index.html. It loads game.js as a module, and centers the game in the window.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My Game</title>
</head>
<body style="margin: 0; height: 100vh; display: flex; justify-content: center; align-items: center;">
    <script type="module" src="game.js"></script>
</body>
</html>

3. Write the Game

Put this in game.js.

import MDog from "https://cdn.jsdelivr.net/gh/MiloKesteloot/MDogEngine@v1.1.1/MDogModules/MDogMain.js";

const position = new MDog.Math.Vector(256, 192);

function main() {
    // Move with the arrow keys
    if (MDog.Input.Keyboard.isDown("ArrowLeft")) {
        position.add(-1, 0);
    }
    if (MDog.Input.Keyboard.isDown("ArrowRight")) {
        position.add(1, 0);
    }
    if (MDog.Input.Keyboard.isDown("ArrowUp")) {
        position.add(0, -1);
    }
    if (MDog.Input.Keyboard.isDown("ArrowDown")) {
        position.add(0, 1);
    }

    // Draw
    MDog.Draw.clear({color: "#1c1c3c"});
    MDog.Draw.rectangleFill(position.x - 8, position.y - 8, 16, 16, "#ff8800");
}

MDog.setActiveFunction(main);

The import line loads MDog Engine and makes the game screen. MDog.setActiveFunction(main) tells MDog Engine to run main 160 times per second, and each run is called a "tick" (see Core). Every tick, the game moves the square if an arrow key is held down, then clears the screen and draws the square.

4. Run the Game

Browsers won't run modules from a file opened straight off your computer, so the game needs to be opened through a local web server. Any of these work:

  • The Live Server extension for VS Code. Right click index.html and pick "Open with Live Server."
  • Opening index.html from WebStorm or another JetBrains editor.
  • Running npx serve or python -m http.server in the game's folder, then going to the address it prints.

An orange square should show up in the middle of the screen, and the arrow keys move it around.

5. Add an Image

Put an image in your assets folder, like assets/player.png, and draw it instead of the square:

MDog.Draw.image("player.png", position.x - 8, position.y - 8);

Images load the first time they're drawn, so an image can be missing for the first few ticks.

6. Add Text

MDog Engine draws text with pixel fonts, which are images in your assets folder. Download one or both of the font images and put them in assets/fonts/:

  • marsfont.png - A small 5 by 5 pixel font.
  • determinationfont.png - A larger 8 by 13 pixel font.

Then draw text with textImage():

MDog.Draw.textImage("Hello world!", 256, 20, "#ffffff", "fonts/marsfont.png", {alignX: "center", size: 2});

7. Share It

The game is a regular web page, so it can be put online anywhere that hosts web pages, like GitHub Pages.

Once this is working, the Examples have some bigger games to look through.

Tips

  • To have the game fill the whole window, add ?fullscreen=true to the end of the URL.
  • The @v1.1.1 in the import is the version of MDog Engine. Your game keeps using that version even after MDog Engine is updated.
