What is MDog Engine?

What is MDog Engine?

MDog Engine is a retro, web-based game engine designed for quick production of games. Games are written in JavaScript and run right in the browser, so they can be shared with just a link.

Everything is drawn with crisp, square pixels on a 512 by 384 pixel screen, which is scaled up to fit the browser window.

Features

  • Shapes, images, sprite sheet animations, pixel font text, and layers with the Draw Module.
  • Keyboard and mouse input with the Input Module.
  • 2D and 3D vectors with the Math Module.
  • Tilemaps and grids with the UI Module.
  • Particle effects with the FX Module.
  • Retro pseudo-3D scenes with the ThreeDee Module.
  • Hitboxes with the Basics Module.
  • A fixed speed game loop, so games run the same on every screen.

How it Works

There's nothing to install. Your game imports MDog Engine straight from the web, gives it a function to run every tick, and uses the modules inside it to draw and read input. Your game's code and art stay in your own project.

import MDog from "https://cdn.jsdelivr.net/gh/MiloKesteloot/MDogEngine@v1.0.0/MDogModules/MDogMain.js";

function main() {
    MDog.Draw.clear();
    MDog.Draw.circle(256, 192, 20, "#ff0000");
}

MDog.setActiveFunction(main);
