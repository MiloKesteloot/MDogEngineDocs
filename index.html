What is MDog Engine?

MDog Engine is a retro, web-based game engine by Milo Kesteloot, designed for making games quickly. Games are written in JavaScript and run right in the browser, so they can be shared with just a link.

Everything is drawn with crisp, square pixels on a small screen (512 by 384 pixels by default), which is scaled up to fit the browser window. The game loop runs at a fixed speed, so games play the same on every computer.

Modules

  • Draw - Shapes, images, pixel font text, animations, and layers.
  • Input - The keyboard and mouse.
  • Math - Math helpers, and 2D and 3D vectors.
  • UI - Pages, tilemaps, and grids.
  • FX - Particles.
  • ThreeDee - Retro pseudo-3D scenes.
  • Asset Manager - Loading text files.
  • Basics - Hitboxes.

How it Works

There's nothing to download. Your game imports MDog Engine from the web, hands it a function to run every tick, and uses its modules to draw stuff and read input. Your code and art stay in your own project.

import MDog from "https://cdn.jsdelivr.net/gh/MiloKesteloot/MDogEngine@v1.4.0/MDogModules/MDogMain.js";

function main() {
    MDog.Draw.clear();
    MDog.Draw.circle(256, 192, 20, "#ff0000");
}

MDog.setActiveFunction(main);
