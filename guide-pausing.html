Pausing the Game

A pause button stops the game from moving, but keeps it on the screen. The easiest way is to split the game into two functions: one that moves everything, and one that draws everything. While the game is paused, only the drawing one runs.

Press Escape to pause and unpause.

How it Works

Every tick, main() checks for Escape with isClicked(), which is only true on the tick the key is pressed, so holding it down doesn't flip back and forth.

While paused is true, update() is skipped, so nothing moves. draw() still runs, so the game stays on the screen. The pause screen is a see-through black rectangle over everything. The last two digits of "#00000099" are how see-through it is, from 00 (invisible) to ff (solid).

Pausing When the Player Leaves

Games often pause themselves when the player switches to another tab. The browser says when that happens with a visibilitychange event:

document.addEventListener("visibilitychange", () => {
    if (document.hidden) {
        paused = true;
    }
});

Timers Pause Too

Anything counted in ticks, like a cooldown or a countdown, stops while the game is paused, as long as it's counted in update(). That's one reason to count ticks instead of using setTimeout(), which keeps going while the game is paused. See Timers and Cooldowns.
